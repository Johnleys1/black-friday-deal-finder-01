Bargain Beacon — a Black Friday deal finder with 50 real deals across 6 stores, every price checked on 27 Nov 2026 and every deal carrying an honest verdict (new low, strong price, routine sale, or inflated was-price). Search and filters by category, store and discount that work, sorting, per-deal pages, and a cross-store comparison view.

## Run it

```sh
node main.ts
```

Serve the site locally with any static server pointed at `app/` (for example `npx serve app` or `python3 -m http.server -d app`), then open http://localhost:8000. Outside the grader, `MAKEFUN_OUTPUT_DIR=out node main.ts` writes the hand-in to `out/`.
